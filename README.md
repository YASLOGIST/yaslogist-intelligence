## Sovereign Intelligence Architecture

A highly advanced, serverless Security, Geopolitical, and Logistics Intelligence platform. Built on a lightweight, high-performance vanilla architecture with a WebGL (AcidSquares) rendering engine. It deploys live tactical layers to monitor maritime shipping lanes, critical subsea cables, and supply chain infrastructure threats in real-time.

### Design Doctrine

| Principle | Implementation |

|---|---|

| **Zero-Server Sovereignty** | 100% static deployment — no backend, no database, no API keys at runtime. |

| **Zero-Build Purity** | No bundler, no transpiler, no framework. The repository *is* the deployment artifact. |

| **Autonomous Ingestion** | A headless Node.js engine wakes every 2 hours on GitHub Actions, scrapes intelligence feeds, enriches via MITRE CVE API, and commits structured JSON. |

| **Native Bilingual Command** | Every UI string and map popup exists in dual Tactical English / Sovereign Military Arabic form with live `RTL/LTR` DOM mutation. |

## ⚙️ Automated CI/CD Pipeline

- **Smart Tagging:** Automated scanner dynamically tags articles with glowing neon badges (e.g., `RANSOMWARE`, `ZERO-DAY`, `APT ACTIVITY`, `DDoS`).

- **Target Intensity Heatmap:** A background scanner analyzes intelligence volume across a rolling 7-day window.

- **Automated CVE Tracking:** Scans live feeds for CVEs, queries the official MITRE API, and populates the Vulnerabilities table.

- **Cadence:** `cron: 0 */2 * * *` — every 2 hours, zero human intervention. Commits as `github-actions[bot]`.
