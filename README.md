##  Sovereign Intelligence Architecture
A highly advanced, serverless Security, Geopolitical, and Logistics Intelligence platform. Built on a lightweight, high-performance vanilla architecture with a WebGL (AcidSquares) rendering engine. It deploys live tactical layers to monitor maritime shipping lanes, critical subsea cables, and supply chain infrastructure threats in real-time.

---

##  Key Features

* **100% Bilingual Engine:** Seamless, real-time toggling between Tactical English and Sovereign Military Arabic with strict `RTL/LTR` DOM adjustments within the live application.
* **Leaflet Tactical Grid:** 
  * 4 foundational reconnaissance maps (Dark Tactical, Satellite, Maritime Ocean, Topographic).
  * Live tracking of shipping vessels and escort combatants (Live AIS & Escorts).
  * Subsea telecommunication cables and 180 KM radar range telemetry.
* **Live Operations Cockpit:** Real-time DEFCON regional threat gauge, active penetration campaign tracking, and critical cyberattack metrics.
* **CVE Matrix & APT Dossiers:** A dynamically updated database targeting sovereign threat intelligence, zero-day vulnerabilities, and state-sponsored actors.
* **Automated CI/CD Pipeline:** A headless Node.js ingestion engine running on GitHub Actions that autonomously scrapes, structures, and commits threat data every 6 hours without human intervention.

---

##  Technical Stack
* **Frontend:** Pure Vanilla JavaScript (ES6+), CSS3 Glassmorphism, Semantic HTML5.
* **Telemetry & Visuals:** Leaflet.js (Custom Layers), Chart.js, WebGL Canvas (`acid-squares-bg.js`).
* **Automation:** Node.js Ingestion Engine executed via GitHub Actions.
